## 业界记忆方案调研 + ADR-0007 补「业界对标」节
- 用户要求搜索业界 RAG 记忆机制方案。WebSearch 两轮（agentic memory / MemGPT / Generative Agents / Mem0 / 会话摘要）。
- 调研结论：强化/衰减/升级/摘要机制业界全部有成熟实现——
  1. **MemGPT/Letta**：内存层级 + LLM 自主 paging in/out；**Queue Manager 递归摘要 `新摘要=摘要(旧摘要+被驱逐消息)` = 会话失忆标准解法（与 ADR-0007 公式一致）**
  2. **Generative Agents**：记忆流 `分数=recency+importance+relevance`，**recency 指数衰减 decay=0.995**（强化/衰减业界实现）；importance LLM 打分 0-10（与 extract_facts 同构）；reflection 定期抽象总结
  3. **Mem0**：add/update/delete 冲突处理（对比本项目只有相似合并）
  4. **"失忆"三原因**（窗口挤掉/没写长期/没召回）+ 遗忘机制（时间衰减因子+访问频率）
- 已更新：ADR-0007 新增「业界对标」节（含对照表 + 3 升级点 + 追问话术）；CONTEXT.md 术语表新增 4 条业界方案；08 文档 3.1 节补「业界对标」一行 + 指向 ADR。

## 分块业界调研 + ADR-0006 补「业界对标」节
- 用户要求调研分块策略业界方案。WebSearch 一轮（chunking strategies 2026 / contextual retrieval / small-to-big / parent-child）。
- 调研结论：
  1. **本项目架构 = 业界 production default**：sureprompts"recursive + parent-document 是生产标配"；viqus"document-structure-aware 最适合 Markdown"；"分块设天花板，其他抬地板"
